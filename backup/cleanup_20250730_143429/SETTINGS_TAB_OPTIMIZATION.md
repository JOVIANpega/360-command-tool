## 🔧 修復內容

### 1. 修復「指令檔案路徑」瀏覽按鈕
**問題**：按下瀏覽按鈕沒有反應，無法選擇檔案

**解決方案**：
- ✅ 添加`filedialog`導入模組
- ✅ 修復`browse_file()`方法，使用正確的檔案選擇對話框
- ✅ 添加即時保存功能，選擇檔案後自動保存到`setup.json["DUT_Control"]["Command_File_Path"]`
- ✅ 添加錯誤處理和用戶反饋

**修復後的功能**：
```python
def browse_file(self, var_name):
    filename = filedialog.askopenfilename(
        title="選取指令檔案",
        filetypes=[("Text files", "*.txt"), ("All files", "*.*")]
    )
    if filename:
        self.vars[var_name].set(filename)
        # 立即保存到setup.json
        setup = load_setup()
        setup["DUT_Control"]["Command_File_Path"] = filename
        save_setup(setup)
```
