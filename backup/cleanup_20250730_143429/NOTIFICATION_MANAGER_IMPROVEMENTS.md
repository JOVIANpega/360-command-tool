### 2. 全域通知伸縮功能實現 ✅

**需求**：實現全域通知的伸縮功能，平常隱藏，用戶點擊往上箭頭才展開

**實現方案**：

#### A. 新的UI架構
- **控制欄（永遠顯示）**：
  - 左側：🔔 全域通知 標籤
  - 中央：最新訊息簡要顯示（一行）
  - 右側：▲ 展開通知 / ▼ 收縮通知 按鈕

- **詳細面板（可伸縮）**：
  - 4行高度的文字顯示區域
  - 滾動條支援
  - 字體控制、清除、歷史、測試按鈕

#### B. 核心功能
1. **狀態切換**：
   - 初始狀態：收縮（只顯示控制欄）
   - 點擊 "▲ 展開通知"：展開詳細面板
   - 點擊 "▼ 收縮通知"：收縮回控制欄

2. **訊息顯示機制**：
   - **收縮狀態**：簡要訊息顯示在控制欄，支援呼吸燈效果提醒
   - **展開狀態**：完整訊息顯示在詳細面板，包含時間戳記

3. **呼吸燈效果**：
   - 僅在收縮狀態下啟動
   - 新訊息到達時按鈕閃爍 3 次
   - 文字變更為 "🔔 ▲ 新通知" 提醒用戶

#### C. 技術實現
```python
def toggle_notification_panel(self):
    """切換通知面板的展開/收縮狀態"""
    if self.is_expanded:
        # 收縮面板
        self.detail_frame.pack_forget()
        self.toggle_button.config(text="▲ 展開通知")
        self.is_expanded = False
    else:
        # 展開面板
        self.detail_frame.pack(fill='both', expand=True, pady=(5, 0))
        self.toggle_button.config(text="▼ 收縮通知")
        self.is_expanded = True
        # 滾動到最底部顯示最新訊息
        self.notification_text.see(tk.END)
```

## 使用說明

### 全域通知伸縮功能使用方式

1. **正常狀態**：
   - 底部顯示簡潔的通知控制欄
   - 包含最新訊息的簡要預覽

2. **展開通知**：
   - 點擊 "▲ 展開通知" 按鈕
   - 顯示完整的通知歷史記錄
   - 支援字體調整、清除、歷史查看等功能

3. **收縮通知**：
   - 點擊 "▼ 收縮通知" 按鈕
   - 回到簡潔的控制欄模式
   - 不影響整體GUI布局

### 通知類型支援

- **info**：藍色文字，一般資訊
- **success**：綠色文字，成功操作
- **warning**：橙色文字，警告訊息  
- **error**：紅色文字，錯誤訊息

### 功能特色

- ✅ 不影響整體排版
- ✅ 支援歷史記錄保存
- ✅ 呼吸燈效果提醒
- ✅ 字體大小調整
- ✅ 一鍵測試功能
- ✅ 訊息類型區分顯示
