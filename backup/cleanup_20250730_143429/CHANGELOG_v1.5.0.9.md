# VALO360 指令通 版本 1.5.0.9 變更日誌

發布日期: 2025-07-17

## 🎯 主要改進

### 🔧 設定檔案系統優化
- **修復設定檔案載入錯誤**: 解決了 `setup.json` 中重複設定項目導致的 `ValueError: invalid literal for int() with base 10: ''` 錯誤
- **清理重複設定**: 移除設定檔案中的重複 `Window_Width`、`Window_Height` 等項目
- **版本資訊修正**: 修復空版本號問題，確保版本資訊正確顯示

### 🖥️ GUI 結構重新設計
- **治具設定重新配置**: 將治具相關設定從「TAB 設定」完全移動至「TAB 測試治具」中
- **儲存按鈕重新設計**: 
  - 將儲存設定按鈕移動到「TAB DUT 控制」區域
  - 採用橘色正方形按鈕設計 (5x2 尺寸)
  - 新增滑鼠懸停效果提升使用體驗

### ⚙️ 統一設定管理系統
- **新增 SharedConfigManager**: 建立統一設定管理器，實現跨模組變數同步
- **延遲初始化機制**: 解決 Tkinter 變數需要 root 窗口的問題
- **即時同步更新**: 所有設定變更即時同步到各個模組
- **設定自動備份**: 強化設定檔案備份機制，避免資料遺失

### 🔄 變數同步聯動功能
同步聯動的設定項目包括：
- COM Port 設定 (DUT 控制 ↔ 治具控制)
- 波特率、資料位、停止位、奇偶校驗設定
- 字體大小設定 (界面/通知/治具)
- 視窗標題與標籤頁名稱
- IP 地址與指令結尾符號
- 測試類別與超時設定

### 🎨 使用者介面改善
- **治具控制 TAB 重新布局**: 
  - 左欄: 基本設定 (字體大小調整)
  - 右欄: 串列埠設定 (波特率、資料位等)
  - 整合測試類別選擇與指令控制
- **設定頁面精簡**: 移除重複的治具設定項目，保持介面簡潔

## 🐛 錯誤修復

### 🔴 關鍵錯誤修復
- **啟動錯誤修復**: 解決程式啟動時的 `ValueError` 錯誤
- **設定檔案結構修正**: 修復 JSON 結構中的重複項目問題
- **視窗關閉錯誤**: 修正程式關閉時的 `TclError` 錯誤提示

### 🟡 效能與穩定性改善
- **記憶體管理優化**: 改善 Tkinter 變數的生命週期管理
- **錯誤處理強化**: 加強各模組的異常處理機制
- **設定載入穩定性**: 提升設定檔案讀取的可靠性

## 🧹 代碼品質提升

### 📁 檔案整理
- **移除無用檔案**: 將測試檔案移動至 backup 資料夾
  - `test_global_notification.py`
  - `test_highlight.py`
  - `fix_encoding.py`
  - `fix_version.py`

### 🏗️ 架構改善
- **模組化設計**: 強化模組間的解耦合
- **共享資源管理**: 統一管理共享配置與狀態
- **代碼複用**: 減少重複代碼，提升維護性
