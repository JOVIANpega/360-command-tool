1) IP 地址欄位（含 + / −，Ping 後自動寫回）

位置：DUT 控制頁的「IP 地址」區塊

在 IP 輸入框 右側新增 +、− 兩個按鈕，與輸入框間保留 4–6 px 間距（避免黏在一起）。

+ / − 的行為：針對 IP 最後一段 octet 做 +1 / −1（範圍 0–255、溢位 clamp）。

當按下「Ping」按鈕時：

取用目前 IP 欄位字串，寫入 settings["DUT"]["ip_address"]。

立即呼叫 save_settings(settings) 寫回 setup.json（不要等到關閉 GUI 才存）。

GUI 啟動時：從 setup.json 讀取 DUT.ip_address，同步顯示到 IP 欄位。

參考實作（Tkinter 範例，請套到現有變數/框架）：

ip_var = tk.StringVar(value=settings["DUT"].get("ip_address", "192.168.11.143"))

def bump_ip(delta: int):
    try:
        parts = ip_var.get().strip().split(".")
        parts[-1] = str(max(0, min(255, int(parts[-1]) + delta)))
        ip_var.set(".".join(parts))
    except Exception:
        pass

tk.Entry(ip_frame, textvariable=ip_var, width=16).grid(row=0, column=0, padx=(0,6))
tk.Button(ip_frame, text="+", width=2, command=lambda: bump_ip(+1)).grid(row=0, column=1, padx=(0,4))
tk.Button(ip_frame, text="-", width=2, command=lambda: bump_ip(-1)).grid(row=0, column=2)

def on_ping():
    settings["DUT"]["ip_address"] = ip_var.get().strip()
    save_settings(settings)
    run_ping(ip_var.get().strip())  # 保留你原本的 Ping 邏輯

ping_btn.config(command=on_ping)

2) 左邊視窗可調整寬度（新增 Splitter，並記住寬度）

目的：左側輸入區塊若太滿，使用者可自行調整寬度；關閉再開也能記住。

用 水平 Paned/Splitter（Tkinter 用 ttk.PanedWindow(orient='horizontal') 或 PyQt 的 QSplitter(Qt.Horizontal)）。

初始寬度 取自 settings["UI"]["left_pane_width"]。

當使用者拖曳分隔線（sash）結束後，更新並 save_settings(settings)。

請把既有的「左側控制區塊」與「右側回應區」放進同一個 splitter 裡。

Tkinter 參考（請對應你現有的 frame 物件）：

paned = ttk.PanedWindow(root, orient="horizontal")
paned.pack(fill="both", expand=True)

paned.add(left_frame, weight=0)
paned.add(right_frame, weight=1)

# 設定初始寬度
root.update_idletasks()
paned.sashpos(0, settings["UI"].get("left_pane_width", 420))

def on_sash_release(event=None):
    try:
        w = paned.sashpos(0)
        settings["UI"]["left_pane_width"] = int(w)
        save_settings(settings)
    except Exception:
        pass

paned.bind("<ButtonRelease-1>", on_sash_release)

3) 「結束字串」欄位值：即時持久化、重開可還原

現況：有 + / − 功能，但關閉 GUI 後會消失。
調整：

將「結束字串」的 StringVar（或綁定模型）在值變更時即時寫回 settings["DUT"]["end_prompt"]，並 save_settings(settings)。

啟動時從 setup.json 載入並顯示。

+ / − 若是切換候選值，點擊後也要觸發同樣的保存。

Tkinter 參考：

end_prompt_var = tk.StringVar(value=settings["DUT"].get("end_prompt", "root"))

def persist_end_prompt(*_):
    settings["DUT"]["end_prompt"] = end_prompt_var.get().strip()
    save_settings(settings)

end_prompt_var.trace_add("write", persist_end_prompt)

end_prompt_entry = ttk.Entry(end_frame, textvariable=end_prompt_var, width=16)
end_prompt_entry.grid(row=0, column=0, padx=(0,6))

# 你的 + / − 按鈕點擊後也要呼叫 persist_end_prompt()

驗收標準（請自動化或手測）

IP 地址

修改 IP → 按 Ping → 立即更新 setup.json。

重開 GUI → IP 欄位顯示剛剛儲存的值。

+ / − 正確調整最後一段數值（0–255）。

左側寬度

可拖曳調整；關閉/重開後仍維持上次寬度。

結束字串

手動輸入或點 + / − 後，關閉/重開仍能還原。

不需按「儲存設定」，變更即生效並持久化。

注意：請維持現有色系與元件樣式；新增的 + / − 與輸入框之間保留 4–6 px 間距（緊湊但不黏在一起）。如果專案使用的是 PyQt/Wx/PySimpleGUI，請等效替換為該框架的 Splitter / 狀態保存方式。

間距設計
與輸入框之間保留 3~5px 的空隙（避免黏在一起）。
+ 與 - 之間也保留 3~5px 間距。
整體保持緊湊，不要像現在一樣「完全貼齊」或「過於分散」。
+、- 按鈕需對齊輸入框的垂直中心，視覺上居中。
這樣做，UI 就會像這樣的結構：
[ 結束字串輸入框 ]  [+] [-]
而不是現在「黏在一起」的情況。
