## 🎯 功能說明

新增「⚡ 快速設定 (獨立更新)」區域,每個設定都有獨立的「更新」按鈕:

### 核心原則

**從 JSON 讀取 → 只更新該欄位 → 寫回 JSON**

- ✅ 安全: 只更新單一欄位,其他欄位完全不受影響
- ✅ 可靠: 從 JSON 讀取完整資料,不會有空字串問題
- ✅ 清楚: 使用者知道更新了什麼

## 🔧 技術實現

### 更新版本號的程式碼

```python
def update_version_only(self):
    """只更新版本號 - 安全方式"""
    # 1. 從 JSON 讀取當前完整設定
    current_settings = load_setup()
    
    # 2. 讀取使用者輸入的新版本號
    new_version = self.vars["version"].get().strip()
    
    # 3. 驗證
    if not new_version:
        messagebox.showerror("錯誤", "版本號不能為空!")
        return
    
    # 4. 只更新版本號這一個欄位
    old_version = current_settings.get("version", "未知")
    current_settings["version"] = new_version
    
    # 5. 寫回 JSON (其他欄位完全不變)
    save_setup(current_settings)
    
    # 6. 成功提示
    messagebox.showinfo("成功", f"版本號已更新!\n\n舊版本: {old_version}\n新版本: {new_version}")
```

### 為什麼這樣安全?

1. **從 JSON 讀取**: 確保有完整的配置資料
2. **只更新一個欄位**: 其他欄位保持原值
3. **驗證**: 確保新值不是空的
4. **寫回 JSON**: 完整的配置寫回,不會遺漏任何欄位

## ✅ 優點

### vs 單一「儲存設定」按鈕

| 比較項目 | 單一按鈕 | 獨立按鈕 (方案 B) |
|---------|---------|------------------|
| **更新範圍** | 所有欄位 (50+) | 單一欄位 |
| **風險** | 高 (一個欄位錯誤就全毀) | 低 (只影響該欄位) |
| **驗證** | 難 (要驗證所有欄位) | 易 (只驗證一個欄位) |
| **使用者體驗** | 不清楚更新了什麼 | 清楚知道更新了什麼 |
| **安全性** | 低 (可能產生空字串) | 高 (從 JSON 讀取完整資料) |

## 💡 使用建議

### 最常用的設定

1. **版本號** - 每次發布新版本時更新
