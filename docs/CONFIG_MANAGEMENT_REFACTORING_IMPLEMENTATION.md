## 🧪 測試指南

### 測試 1: 字體大小調整 (使用 ConfigService)

1. **啟動程式**
2. **進入「DUT 控制」標籤頁**
3. **調整 UI 字體大小滑桿** (例如: 12 → 16)
4. **查看終端機輸出**,應該看到:
   ```
   [ConfigService] 配置服務已初始化
   [DEBUG] 準備儲存UI字體大小: 16
   [ConfigService] 更新 UI 字體大小: 16
   [ConfigService] 字體大小已成功儲存
   [SUCCESS] UI字體大小已儲存: 16 (使用 ConfigService)
   ```
5. **調整內容字體大小滑桿** (例如: 12 → 14)
6. **查看終端機輸出**,應該看到:
   ```
   [DEBUG] 準備儲存內容字體大小: 14
   [ConfigService] 更新內容字體大小: 14
   [ConfigService] 字體大小已成功儲存
   [SUCCESS] 內容字體大小已儲存: 14 (使用 ConfigService)
   ```
7. **重啟程式**
8. **確認字體大小保持為 16 和 14** ✅

### 測試 2: 「設定我」頁面保護

1. **進入「設定我」標籤頁**
2. **點擊「儲存設定」按鈕**
3. **應該看到警告訊息**:
   ```
   功能暫時禁用
   
   此功能正在重構中,以提供更穩定的配置管理。
   
   目前請使用以下方式調整設定:
   
   📝 字體大小調整:
     → 在「DUT 控制」頁面使用滑桿即時調整並自動儲存
   
   📝 其他設定:
     → 程式關閉時會自動儲存視窗大小等設定
   
   預計下次更新將提供統一的配置管理介面。
   造成不便,敬請見諒!
   ```
4. **確認 setup.json 沒有被破壞** ✅

### 測試 3: 降級方案

1. **暫時重命名 `core/config_service.py`** (模擬 ConfigService 不可用)
2. **啟動程式**
3. **調整字體大小**
4. **查看終端機輸出**,應該看到:
   ```
   [WARNING] ConfigService 不可用,使用降級方案: ...
   [SUCCESS] UI字體大小已儲存: 16 (降級方案)
   ```
5. **確認字體大小仍然可以儲存** ✅
6. **恢復 `core/config_service.py`**

## 👥 使用者指南

### 目前如何調整設定

**字體大小**:
1. 進入「DUT 控制」標籤頁
2. 使用頁面上的滑桿調整
3. 設定會自動儲存

**視窗大小**:
- 調整視窗大小後,關閉程式會自動儲存

**其他設定**:
- 暫時無法在「設定我」頁面調整
- 可直接編輯 `setup.json` 檔案 (進階使用者)
