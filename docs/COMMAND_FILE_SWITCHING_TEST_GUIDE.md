# 換 TXT 檔案功能 - 測試指南

**日期**: 2026-02-11  
**功能**: 自動儲存並重新載入指令檔案 (選項 B)  
**狀態**: ✅ 已實施

---

## 🎯 功能說明

當使用者在「設定我」頁面選擇新的 TXT 指令檔案後:

1. ✅ **自動儲存** - 使用 `ConfigService` 儲存檔案路徑到 `setup.json`
2. ✅ **自動載入** - 立即重新載入指令檔案
3. ✅ **自動更新** - 更新 DUT 控制頁面的指令列表
4. ✅ **即時生效** - 無需重啟程式或點擊其他按鈕

---

## 🧪 測試步驟

### 測試 1: 基本功能測試

1. **啟動程式**
2. **進入「設定我」標籤頁**
3. **找到「指令檔案路徑」欄位**
4. **點擊「瀏覽檔案」按鈕**
5. **選擇一個不同的 TXT 檔案** (例如: `command_360.txt`)
6. **應該看到成功訊息**:
   ```
   ✅ 指令檔案已套用並立即生效!
   
   檔案: command_360.txt
   路徑: D:/((Python TOOL/.../command_360.txt
   
   指令列表已自動更新,無需重啟程式。
   ```
7. **切換到「DUT 控制」標籤頁**
8. **確認指令列表已更新** ✅
9. **關閉程式**
10. **重新啟動程式**
11. **確認程式使用新的 TXT 檔案** ✅

### 測試 2: 錯誤處理測試

**測試 2.1: 檔案不存在**
1. 手動編輯 `setup.json`,將 `Command_File_Path` 改為不存在的路徑
2. 點擊「瀏覽檔案」,選擇一個存在的檔案
3. 應該看到錯誤訊息並恢復正常 ✅

**測試 2.2: 檔案格式錯誤**
1. 選擇一個格式錯誤的 TXT 檔案
2. 應該看到警告訊息:
   ```
   ⚠️ 指令檔案路徑已儲存,但重新載入時發生錯誤:
   [錯誤訊息]
   
   請重啟程式以完全套用變更。
   ```

### 測試 3: 終端機輸出驗證

查看終端機輸出,應該看到:
```
[INFO] 指令檔案已選擇: D:/((Python TOOL/.../command_360.txt
[ConfigService] 更新 DUT 設定: Command_File_Path = D:/((Python TOOL/.../command_360.txt
[ConfigService] 字體大小已成功儲存
[SUCCESS] 指令檔案路徑已儲存: D:/((Python TOOL/.../command_360.txt
[SUCCESS] 指令檔案已重新載入,共 XXX 個指令
[SUCCESS] DUT 控制頁面指令已更新
[SUCCESS] 指令列表顯示已更新
```

## ✅ 預期行為

### 成功情況
- ✅ 選擇檔案後立即儲存到 `setup.json`
- ✅ 指令列表立即更新
- ✅ 無需重啟程式
- ✅ 無需點擊其他按鈕

### 錯誤情況
- ⚠️ 檔案不存在 → 顯示錯誤訊息,不儲存
- ⚠️ 檔案格式錯誤 → 儲存路徑,但顯示警告訊息
- ⚠️ 更新 UI 失敗 → 儲存成功,但 UI 可能需要手動重新整理

---

## 🔍 已知限制

1. **檔案格式驗證**
   - 目前只檢查檔案是否存在
   - 不驗證檔案內容格式
   - 如果檔案格式錯誤,會在重新載入時報錯

2. **UI 更新**
   - 依賴 DUT 控制頁面的 `handlers.parse_commands_by_section()` 方法
   - 如果該方法不存在,UI 不會自動更新
   - 使用者需要手動切換標籤頁或重啟程式
