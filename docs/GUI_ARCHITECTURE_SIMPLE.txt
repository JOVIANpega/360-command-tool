
PEGA 指令通 - 簡潔架構圖
================================================================================

主程式層
--------
main.py
  |
  +-- 初始化應用程式
  +-- 載入 setup.json
  +-- 安全簽名驗證
  +-- 啟動 GUI


核心模組 (core/)
----------------
config_manager.py      -> 統一設定管理、讀寫 setup.json
error_handler.py       -> 錯誤處理、日誌記錄
resource_manager.py    -> 資源管理、記憶體監控
async_manager.py       -> 非同步任務管理
performance_monitor.py -> 效能監控


UI 主控制 (ui_parts/)
---------------------
ui_main.py
  |
  +-- SerialUI (主視窗類別)
  +-- TabManager (標籤頁管理器)


5 個主要標籤頁
--------------
TAB 1: ui_components.py       -> DUT 控制 (指令選擇、執行、結果顯示)
TAB 2: ui_manual_command.py   -> 手打指令 (手動輸入、即時執行)
TAB 3: ui_dos_tab.py           -> DOS 批次檔 (批次執行)
TAB 4: ui_settings_tab.py      -> 設定我 (COM/SSH/ADB/超時/UI 設定)
TAB 5: ui_startup_label.py     -> 啟動標籤 (裝置標籤、啟動訊息)


UI 組件模組
-----------
ui_components_base.py     -> 基礎元件、共用樣式
ui_components_input.py    -> 輸入元件 (下拉選單、文字輸入)
ui_components_output.py   -> 輸出元件 (文字區域、日誌顯示)
ui_components_settings.py -> 設定元件


功能處理模組
------------
ui_handlers.py        -> 事件處理、按鈕回調、指令執行
command_processor.py  -> 指令解析、檔案讀取、分類管理
ui_handlers_core.py   -> 核心處理、狀態管理


輔助功能模組
------------
tooltip.py              -> ToolTip 提示系統
notification_manager.py -> 全域通知管理器
font_manager.py         -> 字體管理
shared_config.py        -> 共用設定、全域變數
ui_tab_manager.py       -> 標籤管理


傳輸層 (3 種模式)
-----------------
serial_worker.py -> Console 模式 (COM Port、序列埠通訊)
adb_worker.py    -> ADB 模式 (ADB 連線、Shell 指令)
ssh_worker.py    -> SSH 模式 (SSH 連線、遠端執行)


設定與資料檔案
--------------
setup.json             -> 主設定檔 (視窗大小、COM/SSH 設定、超時設定)
command.txt            -> 預設指令檔
tooltips.ini           -> ToolTip 設定
tooltip_config.txt     -> ToolTip 詳細設定
color_word.txt         -> 關鍵字高亮
user_guide.txt         -> 使用說明
Command_TABLE/         -> 自訂指令檔目錄
FIXTURE/               -> 治具控制腳本


資料流向
--------
使用者操作
  ↓
UI 元件 (ui_components.py, ui_manual_command.py)
  ↓
事件處理器 (ui_handlers.py)
  ↓
指令處理器 (command_processor.py)
  ↓
傳輸層 (serial_worker / adb_worker / ssh_worker)
  ↓
裝置/系統回應
  ↓
結果處理與顯示 (ui_handlers.py)
  ↓
UI 更新 (輸出區域、日誌、通知)
  ↓
設定儲存 (config_manager.py → setup.json)


關鍵特性
--------
✓ 多傳輸模式支援 (Console/ADB/SSH)
✓ 動態指令載入與分類管理
✓ 智慧 ToolTip 系統
✓ 全域通知管理器
✓ 統一設定管理 (setup.json)
✓ 錯誤處理與日誌系統
✓ 資源管理與效能監控
✓ 自動化腳本執行
✓ 批量指令執行
✓ 可自訂超時設定
✓ 歷史記錄管理
✓ 安全簽名驗證
