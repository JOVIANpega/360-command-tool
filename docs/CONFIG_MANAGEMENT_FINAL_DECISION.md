**日期**: 2026-02-11  
**決定**: 徹底禁用「儲存設定」按鈕  
**原因**: UI 元件載入問題無法快速修復,需要大規模重構

## 🔍 問題分析

### 根本原因

**「設定我」頁面的 UI 元件沒有正確初始化,導致 `self.vars` 裡的值全部是空字串。**

當使用者點擊「💾 儲存設定並即刻生效」時:
1. `self.vars["version"].get()` 返回 `""` (空字串)
2. `self.vars["Window_Title"].get()` 返回 `""` (空字串)
3. 所有欄位都是空字串
4. 空字串被寫入 `setup.json`
5. 程式無法啟動

### 為什麼驗證沒有生效?

驗證邏輯確實執行了,但問題是:
- `self.vars` 裡的值**確實是空字串**
- 驗證檢查到空字串,應該拒絕儲存
- **但儲存還是發生了** → 說明驗證邏輯有 bug 或被繞過

### 需要修復什麼?

要徹底修復這個問題,需要:

1. **找出為什麼 UI 元件沒有正確載入值**
   - 檢查 `SettingsTab.__init__()` 的初始化邏輯
   - 檢查 `self.vars` 的綁定邏輯
   - 確保從 `setup.json` 載入值到 UI 元件

2. **重構 `generate_settings_dict()`**
   - 不應該從 UI 讀取值
   - 應該從 `setup.json` 讀取當前值
   - 只更新使用者修改的欄位

3. **使用 ConfigService 統一管理**
   - 移除 `generate_settings_dict()`
   - 改用 ConfigService 的 API
   - 實現即時儲存

**預估工作量**: 2-3 天的重構工作

## 🔧 如何手動編輯 setup.json

### 步驟

1. **關閉程式**
2. **用文字編輯器開啟 `setup.json`**
3. **修改需要的欄位**:
   ```json
   {
     "tab_names": {
       "tab0": "DUT控制1",  // 修改這裡
       "tab1": "治具控制1",  // 修改這裡
       ...
     },
     "Manual_Command": {
       "Hint_Text": "請輸入指令並按執行1"  // 修改這裡
     }
   }
   ```
4. **儲存檔案**
5. **重新啟動程式**

### ⚠️ 注意事項

- 確保 JSON 格式正確 (不要遺漏逗號、引號等)
- 不要刪除任何欄位
- 不要將欄位設為空字串 `""`
- 修改前建議備份 `setup.json`
