## 版本 2.6.7 (2026-04-24)

### ✨ UI 與 經驗優化 (介面重構)
- **介面瘦身計畫**：徹底移除實體預覽框（釋放 80px 垂直空間），確保底部版本資訊完整顯示。
- **進化版 ToolTip V2**：
  - **右側彈出預覽**：指令預覽改為在選單右側橫向彈出，不再遮擋下方的 IP 或設定區塊。
  - **極速反應**：ToolTip 觸發延遲縮短至 0.2 秒。
  - **簡約顯示**：預覽內容僅保留「完整原始碼」，捨棄過多雜訊，讓介面更清爽。
- **通訊選單優化**：
  - **移除粉紅背景**：將 COM 口選單與傳輸方式選單回歸簡約白色，視覺更專業。
  - **精緻化刷新按鈕**：將大塊按鈕縮小為圖示 `🔄`，提升操作流暢度。
- **指令自動載入**：現在點擊分類按鈕即可立即從硬碟重新讀取指令，無需重啟程式。

## 版本 2.6.6 (2026-04-24)

### 🆕 新功能 (核心通訊優化)
- **靜默偵測系統 (Silence Detection)**：在發送指令前自動偵測設備輸出，確保連續 0.3 秒無 Log 輸出才發射，大幅提升 Taurus7 登入穩定性。
- **仿人類慢速打字模式 (Typewriter Mode)**：針對登入指令採單個字元發送（50ms 間隔），解決設備高負載下因連打造成的輸入丟失。
- **智慧型 Prompt 匹配**：支援不區分大小寫匹配，並優化了對 `[sudo] password for pega:` 等複雜提示符號的識別。

### 🎨 UI 與 介面改進
- **指令預覽儀表板 (Step Preview Dashboard)**：
  - 改用 **橫向流動佈局** 與 `➔` 箭頭，使多步驟指令更易於閱讀。
  - **固定高度防抖動**：預覽區塊鎖定為 80px 高度，防止 UI 元件隨指令長度跑位。
  - **自動過濾雜訊**：主畫面過濾 `<<...>>` 標記，顯示純淨指令。
  - **懸停詳細資訊**：滑鼠懸停於預覽區時，自動顯示包含原始標籤的完整指令詳情。
  - **等寬字體顯示**：全面改用 `Consolas` 字體提升指令對齊感。

### 🔧 修復
- 修復了 `ui_components.py` 中重複定義 `on_cmd_selected` 導致優化邏輯失效的問題。
- 修復了 f-string 中包含反斜線導致的語法相容性問題。

## 版本 1.10 (2025-08-16)

### 🆕 新功能
- **完整 ToolTip 系統**：為所有按鈕、下拉選單、輸入框等 UI 元件添加提示功能
