# JOVIAN指令工具 更新日誌

## 版本 2.6.17 (2026-04-28)

### 🚀 指令載入自動化與穩定性
- **指令檔案自動同步**：在「設定」分頁選取新的指令 TXT 檔案後，系統現在會**自動儲存**路徑並**即時刷新**「DUT 控制」分頁的指令清單，無需手動儲存或重啟程式。
- **更新成功彈窗優化**：修復了選取檔案後成功提示視窗可能被主程式遮擋的問題，現在提示視窗將強制顯示在最前端。
- **配置持久化修正**：修復了切換分頁時，新選取的指令檔案路徑可能被舊配置覆蓋的 Bug。

---


## 版本 2.6.15 (2026-04-27)

### 🎨 介面還原與優化
- **移除深色模式 (Revert Dark Mode)**：根據使用者回饋，深色模式可能導致部分介面元素判讀困難，故已完整還原至經典淺色專業介面。
- **恢復綠色標籤樣式**：修復了「治具」分頁（Handover）在選取時會變成藍色的問題，現在將保持經典的**綠色背景**。

### 🔍 關鍵字高亮增強 (User Customizable)
- **自訂高亮關鍵字**：在「設定」分頁右側新增「關鍵字高亮設定」區塊。使用者現在可以自行定義要凸顯的文字與對應顏色（支援 red, green, blue 或 HEX 色碼）。
- **即時生效**：在設定頁面修改關鍵字並儲存後，無需重啟程式，Console 輸出區域即可立即應用新的高亮規則。

---

## 版本 2.6.14 (2026-04-27)

### 🌓 視覺與風格優化 (Premium UI)
- **深色模式 (Dark Mode) V2**：再次進化！調整背景為 `#252526` 柔和灰，避免純黑的高對比疲勞。優化了 Labelframe 的標題配色與邊框質感，使介面更具專業感。
- **分頁樣式修復 (Handover Restoration)**：恢復了「治具」分頁（或名稱包含 Handover 的分頁）在選取時的經典**綠色標籤**樣式，並加大了標籤文字字體，提升識別度。
- **文字大小精準控制**：修正了主題切換時字體大小失效的問題。現在分頁標籤、輸入框、輸出視窗與按鈕字體均會根據設定值正確縮放（標籤文字額外加大 2px）。
- **關鍵字高亮 (Keyword Highlighting)**：新增關鍵字自動偵測功能。讀取到 `ERROR`, `FAIL`, `TIMEOUT` 等錯誤關鍵字時會以**紅色**顯示，`SUCCESS`, `OK` 則以**綠色**顯示。

### 🛠️ 功能增強
- **日誌導出 (Export Log)**：在 Console 輸出區域點擊右鍵新增「導出日誌」選項，可將當前內容存為帶時間戳的 `.txt` 檔案。

## 版本 2.6.13 (2026-04-27)

### 🔧 設定與持久化修復
- **超時設定自動同步**：修復了「超時(秒)」設定在重啟後會重置為 30 的問題。現在主分頁、設定分頁與手動輸入分頁的超時欄位已完全同步，並支援變更後自動延遲保存。
- **全域變數綁定**：優化了 SharedConfig 管理器，確保所有 UI 元件共享同一套核心設定，消除數據不一致。

### 🎨 輸出顯示優化
- **指令顏色高亮**：將指令發送時的標頭顏色從紫色改為**藍色**，顯著提升指令與回應內容的可辨識度。
- **手動指令視覺優化**：在「手動輸入」分頁中執行的指令現在也會以藍色顯示。

### 📦 版本管理
- **全平台同步**：同步更新 setup.json、HTML 使用指南、EXE 資源文件與打包腳本，確保版本號一致。

## 版本 2.6.7 (2026-04-24)

### ✨ UI 與 經驗優化 (介面重構)
- **介面瘦身計畫**：徹底移除實體預覽框（釋放 80px 垂直空間），確保底部版本資訊完整顯示。
- **進化版 ToolTip V2**：
  - **右側彈出預覽**：指令預覽改為在選單右側橫向彈出，不再遮擋下方的 IP 或設定區塊。
  - **極速反應**：ToolTip 觸發延遲縮短至 0.2 秒。
  - **簡約顯示**：預覽內容僅保留「完整原始碼」，捨棄過多雜訊，讓介面更清爽。
- **通訊選單優化**：
  - **移除粉紅背景**：將 COM 口選單與傳輸方式選單回歸簡約白色，視覺更專業。
  - **精緻化刷新按鈕**：將大塊按鈕縮小為圖示 `🔄`，提升操作流暢度。
- **指令自動載入**：現在點擊分類按鈕即可立即從硬碟重新讀取指令，無需重啟程式。

## 版本 2.6.6 (2026-04-24)

### 🆕 新功能 (核心通訊優化)
- **靜默偵測系統 (Silence Detection)**：在發送指令前自動偵測設備輸出，確保連續 0.3 秒無 Log 輸出才發射，大幅提升 Taurus7 登入穩定性。
- **仿人類慢速打字模式 (Typewriter Mode)**：針對登入指令採單個字元發送（50ms 間隔），解決設備高負載下因連打造成的輸入丟失。
- **智慧型 Prompt 匹配**：支援不區分大小寫匹配，並優化了對 `[sudo] password for pega:` 等複雜提示符號的識別。

### 🎨 UI 與 介面改進
- **指令預覽儀表板 (Step Preview Dashboard)**：
  - 改用 **橫向流動佈局** 與 `➔` 箭頭，使多步驟指令更易於閱讀。
  - **固定高度防抖動**：預覽區塊鎖定為 80px 高度，防止 UI 元件隨指令長度跑位。
  - **自動過濾雜訊**：主畫面過濾 `<<...>>` 標記，顯示純淨指令。
  - **懸停詳細資訊**：滑鼠懸停於預覽區時，自動顯示包含原始標籤的完整指令詳情。
  - **等寬字體顯示**：全面改用 `Consolas` 字體提升指令對齊感。

### 🔧 修復
- 修復了 `ui_components.py` 中重複定義 `on_cmd_selected` 導致優化邏輯失效的問題。
- 修復了 f-string 中包含反斜線導致的語法相容性問題。
