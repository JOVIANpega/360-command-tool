📖 程式概述

PEGA指令通 是一個專業的裝置控制工具，支援：

  • 🔧 透過 COM 口（Console 模式）執行測試指令
  • 📱 透過 ADB（ADB 模式）對 Android/Linux 裝置下達指令
  • 🌐 透過 SSH（SSH 模式）遠端執行指令 NEW!
  • 📊 即時顯示指令執行結果，支援關鍵字高亮
  • 📁 自訂指令檔案與分類，支援多重指令以分隔符執行
  • 🎯 提供 Ping 檢查與網路診斷

✨ 最新功能與行為 (V2.5.4)

  • 🛑 強制停止功能：在「手動輸入指令」頁面新增「停止」按鈕，可即時中斷執行中的長指令。
  • ⚙️ 全新 V2 工作器架構：重構底層通訊邏輯 (Serial/ADB/SSH Worker V2)，提升指令執行穩定性與回應速度。
  • 📟 串列埠波特率支援：Console 模式現在支援自訂波特率（預設 115200），可在設定中調整。
  • 🔗 治具控制TAB字体联动：治具控制TAB的界面字体现在与DUT控制TAB完全联动。
  • 🌐 SSH 功能完整版：完全替代 Teraterm，支援 Dropbear SSH 和 OpenSSH。
  • 🔐 智慧認證機制：自動適配不同 SSH 伺服器的認證方式，支援空密碼認證
  • 💻 完整環境載入：使用登入 shell 執行指令，確保所有環境變數和函式庫正確載入
  • 安全啟動檢查：執行檔同資料夾需有 sign_DOC.txt 且包含 JOVIAN，否則 GUI 不會開啟。
  • IP 集中管理：設定頁的「預設 IP」改為可編輯下拉選單，來源為 IP 歷史，最多 5 筆（去重、最近使用置頂）。
  • 即時生效：在設定頁輸入或選擇 IP 後按「儲存並立即生效」，會寫回設定並同步所有頁面的 IP 下拉。
  • 行為調整：DUT 控制頁的「+ IP」新增按鈕已停用；Ping 僅作為網路測試，不再寫入 IP 歷史。

🎯 基本使用方法

快速開始（Console 模式）

  1. 選擇 Console 模式
  2. 選擇 COM 口
  3. 選擇分類與指令
  4. 按下「執行指令」
  5. 查看右側輸出

快速開始（ADB 模式）

  1. 確認裝置已開啟 USB 調試並連線，adb devices 可看到 device
  2. 在程式選擇 ADB 模式
  3. 選擇分類與指令（支援多重指令，以分隔符 ==> 分隔）
  4. 按下「執行指令」後，程式將以 adb shell 執行

快速開始（SSH 模式）🌐

  1. 設定 SSH 連線資訊：
    • 進入「設定」標籤頁
    • 在 SSH 設定區塊設定主機 IP、埠號、帳號密碼
    • 帳號格式：使用者名稱/密碼（如 root/ 表示空密碼）
    • 點擊「儲存設定並即刻生效」
  2. 執行 SSH 指令：
    • 回到「DUT控制」標籤頁
    • 選擇 SSH 模式
    • 選擇分類與指令
    • 按下「執行指令」，程式將透過 SSH 連線執行
🔒 SSH 安全提示：
  • 確保目標設備 SSH 服務正常運行
  • 檢查網路連通性（可使用 Ping 功能測試）
  • SSH 模式支援 Dropbear SSH 和 OpenSSH
  • 程式會自動適配認證方式，支援空密碼認證
⚠️ 注意事項：
  • 指令執行中可再次點擊「執行指令」以中止
  • 若指令時間過長，請調整超時設定
  • 結束字串（預設 root）可判斷流程是否完成

📝 指令檔案設定

指令檔案格式

指令檔案使用 .txt 格式，支援分類與註解。

基本格式：

==分類名稱== 顯示名稱|實際指令 顯示名稱|實際指令 ==另一個分類== 顯示名稱|實際指令

範例檔案內容：

==全部指令== 查看版本|pegacmd version 查看系統資訊|cat /proc/cpuinfo 重啟系統|reboot ==單板指令== LED測試|echo 1 > /sys/class/leds/led0/brightness GPIO測試|cat /sys/kernel/debug/gpio 溫度檢測|cat /sys/class/thermal/thermal_zone0/temp ==整機指令== 網路測試|ping -c 3 8.8.8.8 磁碟檢查|df -h 記憶體檢查|free -m ==出貨OQC== 最終測試|echo "Final Test Complete" 品質檢查|cat /proc/version

分隔符與多重指令

可在設定中自訂分隔符（預設 ==>）。同一行中以分隔符分隔可連續執行多個指令。

分類按鈕自動生成

程式會依據指令檔案中的分類標記，自動在 DUT 控制頁生成分類按鈕：

  • 🔵 每個 ==分類名稱== 會生成一個按鈕
  • 🔄 切換指令檔時自動更新
  • 📊 顯示每個分類的指令數量

🔧 常見問題

Q: ADB 連線顯示 offline 或找不到裝置？

解決方法：
1. 在命令列執行 adb devices 檢查狀態
2. 重新插拔 USB 或執行 adb kill-server && adb start-server
3. 確認已開啟 USB 調試並授權

Q: 指令執行超時？

解決方法：
1. 增加超時時間設定
2. 檢查指令正確性
3. 確認結束字串設定是否正確（例如 root）

Q: SSH 連線失敗？🌐

解決方法：
1. 確認設備 SSH 服務運行：ssh root@192.168.x.x
2. 檢查網路連通性：使用程式內建 Ping 功能
3. 驗證帳號密碼格式：使用者名稱/密碼
4. 空密碼使用 root/ 格式
5. 查看輸出區域的詳細錯誤訊息

Q: SSH 連線成功但指令執行失敗？

可能原因：
• 指令在 SSH 環境中不存在
• 權限不足
• 環境變數未正確載入

解決方法：
1. 確認指令在目標設備上存在
2. 檢查使用者權限
3. 程式已自動載入完整環境，如仍有問題請檢查設備設定

Q: 如何選擇最佳傳輸模式？

建議選擇順序：
1. SSH 模式：網路連線穩定，安全性最高
2. Console 模式：直接 COM 口連線，最穩定
3. ADB 模式：Android/Linux 設備開發調試

選擇依據：
• 有網路且支援 SSH → 優先選 SSH
• 僅有 COM 口 → 選 Console
• Android 開發 → 選 ADB
