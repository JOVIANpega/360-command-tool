# VALO360 指令通 - V1.6.0.3 更新日誌

## 🚀 版本資訊
- **版本號**：V1.6.0.3
- **發布日期**：2025-01-28
- **開發者**：VALO360 團隊

## ✨ 主要更新

### 🎨 GUI 介面風格優化
- **Windows 風格設計**：採用淺灰白底色系，視覺清爽，貼近 Windows 系統內建應用程式
- **統一字體與樣式**：使用 Segoe UI 字體，統一各元件大小與間距
- **元件分組優化**：使用 LabelFrame 分組框架，清晰劃分功能區塊
- **按鈕樣式統一**：所有按鈕大小一致，添加懸停效果
- **Tab 頁籤優化**：改進頁籤樣式，提升視覺層次感

### 📝 全域通知系統優化
- **呼吸顯示效果**：新增「呼吸顯示」效果，自動處理長文字顯示
- **智能分行處理**：長訊息自動分行，每行顯示2.5秒後輪流切換
- **字體大小控制**：通知字體大小控制按鈕 [+][-] 直接整合到通知區域
- **設定儲存**：字體大小設定自動儲存至 setup.json，下次啟動自動套用

### 🔄 ToolTip 與全域通知整合強化
- **全面提示支援**：所有 UI 元件都添加了 Tooltip 提示文字
- **顯示效果優化**：添加淡入淡出效果，提升使用體驗
- **延遲顯示**：設定 500ms 延遲顯示，避免干擾操作
- **全域通知整合**：滑鼠懸停時，提示內容同步顯示在全域通知欄

### 🧰 程式架構改進
- **統一樣式管理**：集中管理 UI 樣式，便於維護與擴展
- **元件分組設計**：按功能分組管理元件，提升代碼可讀性
- **間距與對齊優化**：統一元件間距與對齊方式，視覺更協調
- **響應式佈局**：優化窗口大小變化時的元件佈局

## 🔧 技術細節

### 修改的檔案
- `ui_parts/ui_components_base.py`：實現 Windows 風格的 UI 基礎元件
- `ui_parts/notification_manager.py`：實現呼吸顯示效果與字體控制功能
- `ui_parts/tooltip.py`：優化 ToolTip 顯示效果，添加淡入淡出
- `ui_parts/ui_components.py`：統一按鈕樣式、間距，確保所有元件都有 tooltip
- `ui_parts/ui_main.py`：實現 Windows 風格的 Tab 設計
- `version_info_zh.py`：更新版本號至 V1.6.0.3
- `setup.json`：更新版本號並新增字體大小設定

### 使用方式
1. **元件提示**：滑鼠懸停在任何 UI 元件上，可查看該元件的功能說明
2. **長文字通知**：當通知文字較長時，系統會自動分行並以呼吸方式輪流顯示
3. **字體大小調整**：使用通知區域右側的 [+][-] 按鈕調整通知字體大小
4. **關閉提示**：在「其他設定」區域可以關閉元件提示功能

## 📋 已知問題
- 在某些低解析度螢幕上，部分元件可能顯示不完整
- 非 Windows 系統可能無法完全顯示 Windows 風格
