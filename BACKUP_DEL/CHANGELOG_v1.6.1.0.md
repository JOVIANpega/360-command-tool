# VALO360 指令通 V1.6.1.0 更新日誌

## 新功能

1. **指令間隔符號自訂功能**
   - 在設定頁面新增「指令間隔符號」欄位，允許使用者自訂指令間隔符號
   - 預設值為 `|`，可自訂為任意字符，如 `||` 或 `$$`
   - 修改後立即生效，不需重新啟動應用程式
   - 所有使用者執行的指令，在送出前會將預設的 `|` 替換為設定中指定的符號

## 錯誤修復

1. **修復 ToolTipManager 相關問題**
   - 新增 `set_all_enabled` 方法以解決 ToolTip 管理器初始化錯誤
   - 改善 ToolTip 顯示邏輯，提高使用者體驗

2. **修復 UI 組件初始化問題**
   - 修復 `list_com_ports` 函數未正確導入的問題
   - 優化 UI 組件初始化流程，提高應用程式穩定性

## 其他改進

1. **程式碼優化**
   - 改善錯誤處理機制
   - 優化設定檔讀寫邏輯
   - 提高應用程式整體穩定性

2. **使用者體驗優化**
   - 設定項目即時生效，提升使用者體驗
   - 改進錯誤提示訊息，使其更加清晰明確
