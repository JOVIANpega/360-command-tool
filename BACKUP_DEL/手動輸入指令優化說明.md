# 手動輸入指令標籤頁優化說明

## 🔁 【互動內容顯示方式】優化

### 改進內容：
1. **移除互動模式按鈕**：移除了「退出互動」與「進入互動模式」按鈕，簡化使用者介面
2. **垂直排列顯示**：串口執行結果改為垂直排列，一行一行顯示，不再水平擠在一起
3. **直接輸入功能**：使用者在執行結果框中按 Enter 鍵或 Ctrl+V 可直接送出指令執行

### 範例顯示格式：
```
root@MU310:~# uci -P /var/state get pega.led.booting_state
System_Ready
root@MU310:~#
```

## 🔁 【COM Port 顯示邏輯】優化

### 改進內容：
1. **與 DUT 控制標籤頁一致**：COM Port 顯示邏輯與 DUT 控制標籤頁保持一致
2. **顯示 Port 類型**：可以顯示「DM PORT / AT PORT / NMEA PORT」等標示
3. **錯誤提示**：當 COM 無法使用時，在執行結果框中顯示適當錯誤提示（如：存取被拒、未連線等）

### 顯示範例：
- `COM3 - DM PORT`
- `COM4 - AT PORT`
- `COM5 - NMEA PORT`

## 📂 【指令檔案清單邏輯】優化

### 改進內容：
1. **自動載入設定**：切換到「手動輸入指令」標籤頁時，立即讀取 `setup.json` 中的 `Manual_Command_File_Path` 設定值
2. **顯示全部指令**：不只顯示 15 條，顯示全部指令內容，並加入捲動功能
3. **分組設計**：依據檔名自動產生切換按鈕或分類按鈕
4. **分組按鈕**：UI 參考 DUT 控制標籤頁按鈕設計，使用者點擊後可載入該指令組所有條目

### 分組範例：
```
[KANGAROO 指令組] [MB 指令組] [LED 測試指令組] [網路測試指令組]
```

### 支援的指令檔案格式：
```txt
==KANGAROO 指令組==

booting_state=uci -P /var/state get pega.led.booting_state
get_model=atcli at+cgmm
fw_version=uci -P /var/state get pega.fw.cur_ver

==MB 指令組==

build time=cat /etc/pega_fwinfo
EXIT=exit
Login=root==>oelinux123==>cat /etc/pega_fwinfo
```

## 🔚 【資源釋放與清理】優化

### 改進內容：
1. **關閉所有 COM Port**：關閉 GUI 時務必關閉所有 COM Port
2. **清除快取**：清除已記錄的快取、自訂指令記錄
3. **避免 Port 佔用**：避免任何 port 被佔用導致重啟無法使用
4. **設定檔寫回**：同時該寫回 `setup.json` 的資料都要寫回

### 清理項目：
- 關閉所有串口連接
- 清除指令歷史記錄
- 清除指令分組快取
- 保存當前設定到 `setup.json`

## 🎯 【其他優化項目】

### 1. 指令清單顯示改進
- 使用 `ScrolledText` 替代 `Listbox`，提供更好的文字顯示
- 支援文字選擇和複製功能
- 顯示指令標籤和實際指令內容

### 2. 快捷鍵支援
- Enter 鍵：在指令輸入框中執行指令
- Ctrl+V：在輸出視窗中貼上剪貼簿內容
- Ctrl+C：複製選中的文字

### 3. 錯誤處理
- 完善的錯誤提示機制
- 串口連接失敗時的適當提示
- 檔案載入失敗時的錯誤處理

### 4. 設定管理
- 使用 `Manual_Command_File_Path` 作為指令檔案路徑設定
- 自動保存使用者設定
- 支援多個預設指令檔案路徑

## 📝 【使用說明】

### 基本操作：
1. 選擇 COM Port（會顯示 Port 類型）
2. 設定傳輸方式和超時時間
3. 在指令輸入框中輸入指令並按執行
4. 或在執行結果框中直接輸入指令

### 指令檔案操作：
1. 點擊「選擇檔案」載入指令檔案
2. 使用分組按鈕切換不同指令組
3. 在指令清單中選擇指令並複製到輸入框
4. 點擊「重新載入」重新解析指令檔案

### 輸出操作：
1. 在執行結果框中按 Enter 輸入指令
2. 按 Ctrl+V 貼上剪貼簿內容
3. 按 Ctrl+C 複製選中文字
4. 點擊「清除輸出」清空執行結果

## 🔧 【技術實現】

### 主要檔案：
- `ui_parts/ui_manual_command.py`：手動輸入指令 UI 模組
- `setup.json`：設定檔，包含 `Manual_Command` 區段
- `Command_TABLE/test_manual_commands.txt`：測試指令檔案

### 關鍵方法：
- `refresh_com_ports()`：刷新 COM Port 列表
- `load_command_file()`：載入指令檔案
- `parse_command_file()`：解析指令檔案並分組
- `create_group_buttons()`：創建分組按鈕
- `on_close()`：資源清理

### 設定項目：
```json
{
  "Manual_Command": {
    "Serial_COM_Port": "",
    "Command_Timeout_Seconds": "3",
    "Command_Transport_Mode": "Console",
    "Manual_Command_File_Path": "Command_TABLE/test_manual_commands.txt",
    "Pane_Sash_Position": "400",
    "Hint_Text": "請輸入指令並按執行"
  }
}
```
